##Student Marks Calculator (Java)
A simple Java-based Student Marks Calculator that calculates a student's total marks, average, percentage, and grade based on marks obtained in five subjects. The program uses Java concepts such as user input, loops, conditional statements, and arithmetic operations to generate a student result.
##FEATURES
Accepts student name and subject marks
Calculates total marks and average
Computes overall percentage
Assigns grades based on marks
Validates marks within the range of 0–100
##Technologies Used
Java
Scanner class
Conditional statements (if-else)
Loops and arithmetic operators
##Purpose
This project is designed for beginners to practice basic Java programming concepts and understand how to build a simple console-based application.
